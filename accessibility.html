Accessibility

Our Commitment

TR3 Media Solutions is committed to ensuring that our website is accessible to all users, including those with disabilities. We aim to meet or exceed WCAG 2.1 Level AA standards.

Accessibility Features

Our website includes the following accessibility features:

  • Semantic HTML structure with proper heading hierarchy
  • Skip navigation link to bypass repeated content
  • Sufficient color contrast ratios for text and interactive elements
  • Keyboard-navigable interface with visible focus indicators
  • Descriptive alt text for images
  • ARIA labels for interactive elements and navigation landmarks
  • Responsive design that supports browser zoom up to 200%
  • Form labels and error messages associated with their inputs

Known Limitations

We are continuously working to improve accessibility. If you encounter any barriers while using our website, we want to know about it so we can address the issue.
